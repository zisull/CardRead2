活字 Letterpress
补位：现有 5 个主题没有「纸/印刷物」质感的中性款。可当日常主力皮，不像航海/唱片那样有强主题负担。
  • 母题：铅字条导航（反色块即选中）、书脊色带 hero、硬边偏移投影、朱印落款
  • 字体：Georgia / 宋体系，全大写宽字距 kicker
  • 双模：和纸浅底 ↔ 墨黑深底，靠 data-mode 切 CSS 变量
  • 列表 = 编号目次行（NO.01 + 进度条）；网格 = 卡片版心

风险最低、最耐看；辨识度靠硬边投影 + 反色导航而非插画。

终端 TTY / CRT
补位：全站唯一等宽 + 荧光调。把「藏书」变成挂载的设备，信息密度最高的一版。
  • 母题：扫描线 + 暗角 + 文字辉光、❯ shelf 命令式导航、/dev/bk00 设备名
  • 进度 = ASCII 柱状块 [█████░░░]；blink 光标在书名后
  • 三模：磷绿 / 琥珀 / 纸墨（浅）；底栏可关扫描线、ASCII 块、光标闪烁
  • 侧栏 = STAT + TAIL 日志流，天然贴合已有「日志」页

扫描线/辉光对长文本有干扰，只适合书架页，阅读窗建议沿用现有主题。

浮世绘 Ukiyo-e 版元
补位：现有「国风韵」是水墨留白路线；这版走木版画强色块 + 装饰边框，是另一种东方。
  • 母题：青海波形分割线、二重框一枚绘、书脊竖排题名、算木进度（ladder）
  • 配色：和纸靛蓝 + 朱色落款；暗模叫「藍摺」
  • 侧栏 = 掛軸造型统计（上下轴杆），底部富士+水面小画
  • 完成书盖「畢」字圆印，读进度写作「墨含み」

装饰最重，与国风韵会被用户视为同族；若要上，建议两者只留其一。

暗房 Darkroom
补位：和「黑胶片」同为复古硬件，但换的是冲洗/相纸语言，视觉母题不撞车。
  • 母题：接触印样（黑底+齿孔条）、照片白边斜贴、安全灯呼吸点、曝光直方图当进度
  • 隐喻：读书 = 显影。未读=底片、在读=显影中、读完=已定影
  • 双模：暗房（深）↔ 光箱（浅，相纸摊开）；底栏可关安全灯
  • 侧栏 = 曝光计 + 药液清单（D-76/F-5），把统计页信息前置

最"有性格"的一版；齿孔/白边细节多，移植工作量最大。
